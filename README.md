# शुभाषिणी ♥ विष्णु — Interactive Wedding Invitation

A modern, highly interactive, and animated static Hindi wedding invitation website. No build tools, backend, or paid hosting required.

## Live Website
🌐 **[https://sanjivkumar09.github.io/subhashini-vishnu-wedding/](https://sanjivkumar09.github.io/subhashini-vishnu-wedding/)**

## Features
- 🌸 **Interactive Petal Rain & Touch Bursts**: Realistic rose and marigold petals falling in the background, with interactive petal/sparkle bursts on screen taps and clicks. Includes a toggle to pause/play.
- ⏳ **Live Countdown Timer**: Real-time ticking countdown to Thursday, 03 December 2026, 8:00 PM IST (Days, Hours, Minutes, Seconds) with animated card flips.
- 📅 **Calendar Integration**: One-click "Add to Google Calendar" and instant download for Apple / phone calendar (`.ics` file).
- 🎵 **Auspicious Mangal Dhwani**: Ambient Indian classical wedding soundscape (warm Tanpura drone + Raag Bilawal chime harmonics) powered by the native Web Audio API with animated equalizer sound bars. Zero external dependencies required.
- 🙏 **Interactive Blessings Counter**: Guests can tap "आशीर्वाद दें" to shower celebratory petals and register their blessings (saved persistently in `localStorage`).
- 📜 **Full-Screen Card Gallery & Lightbox**: Interactive gallery showcasing the physical wedding invitation cards (`card-1.jpg`, `card-2.jpg`, `card-3.jpg`) with zoom, previous/next buttons, keyboard controls, and mobile swipe gestures.
- 💬 **WhatsApp Wish Sender & Share**: Pre-formatted auspicious blessing messages and direct WhatsApp sharing for family and friends.
- 📍 **Venue Navigation**: Quick link to Google Maps directions and one-tap "Copy Address" with instant toast feedback.
- 📱 **Floating Navigation Dock**: Glassmorphism mobile-friendly bottom dock for quick section jumping.
- ♿ **Accessibility & Performance**: Smooth 60fps animations, fully responsive across smartphones, tablets, and desktops, with automatic reduced-motion support.

## Preview locally
Open `index.html` in any browser. Keep the `assets` folder beside it.

## Publish with GitHub Pages
1. Create a new GitHub repository (Public is simplest for Pages).
2. Upload `index.html`, `README.md`, and the complete `assets` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then Save.
6. Wait for GitHub to publish the site. Your shareable URL will look like:
   `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`
